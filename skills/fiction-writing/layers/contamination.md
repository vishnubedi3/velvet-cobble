# Canon contamination

Generated or Arena working material accidentally presented as established canon.

| Pattern | Finding |
|---|---|
| Output `presents_as_canon` / `treat_as_established` on a fact not on `main` | `CX-CONTAMINATION` BLOCK |
| Citing the Generation Contract as a world source | `CX-CONTAMINATION` BLOCK |
| Copying a PASS report into `02-canon/` | Out of band — the skill never writes there |
| Arena `DEVELOPMENTAL` / `PROPOSED` / `EXPLORATORY` labeled established | `CX-SPLASH-PROPOSED` or `CX-CONTAMINATION` |
| Unadmitted draft cited as CANON | `CX-ADMISSION` |

Admission remains [`../CANON_ADMISSION_PROTOCOL.md`](../CANON_ADMISSION_PROTOCOL.md). Contamination is the *failure* of that protocol, detected before or after generation.
