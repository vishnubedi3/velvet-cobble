# Constraint bands (hard vs soft)

The generator must know what it **must obey** versus what is **context**.

| Band | Obey? |
|---|---|
| **HARD CONSTRAINTS** | Yes. Established `main` canon. Charter. Mysteries. Negative space. |
| **SOFT CONTEXT** | Use to understand; do not treat as extra established facts. Clarifications of `main`. Compatible working development. |
| **CURRENT AUTHORIAL DIRECTION** | Influence the next chapter where appropriate. Not established historical fact. |
| **PROVISIONAL MATERIAL** | Only if the request permits working material. Never present as established. |
| **FORBIDDEN ASSUMPTIONS** | Must not assume. |

The generator may not move an item from PROVISIONAL into HARD. That is `CX-BYPASS` / `CX-CONTAMINATION`.
