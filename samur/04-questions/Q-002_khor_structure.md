# Q-002 The Khor's size and internal structure

Status: OPEN
Date: 2026-08-26
Related: GEO-01 (§5, §6); will constrain FOR-01 (the horse-people's own history), DYN-01 (the frontier policy), MIL-01 (the hard frontier), ECO-01 (the horse/salt/silver trade)
Why it matters: whether the Khor is one confederation or several horse-people changes the empire's entire northern strategy (a single treaty partner vs. playing rivals against each other), the horse price, and the shape of the northern military response.
Current best guesses: several competing horse-people with a loose seasonal assembly (a steppe pattern); a single dominant horde is *less* likely (a single strong horde is a different strategic object and would need its own FOR file first).
