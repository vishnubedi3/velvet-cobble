# site/ — Independent Website Project

This directory is an independent project within the repository. It is the working environment for the reader-facing website. It is **not** part of the authoring project and is **not** governed by the root `AGENTS.md`, `PROJECT.md`, or any authoring directives.

The website agent owns this directory and will define its own governance, architecture, workflow, and documentation.

The only practical relationship to the authoring project is that this directory may receive approved narrative material from `samur/narrative/` for publication.
