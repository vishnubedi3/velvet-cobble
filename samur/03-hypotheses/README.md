# Working Hypotheses

Plausible but unconfirmed explanations or models. **Never citable as canon.**

## Entry format

```
# H-<NNN> <Short name>
Status: HYPOTHESIS
Date: YYYY-MM-DD
Origin: [canon IDs / research files]
Claim: one sentence.
Support: why it is plausible.
Confirm if: observable consequences in canon.
Falsify if: observable contradiction.
```

## Lifecycle

Promotion to CANON, or retirement (marked RETIRED with reason), always goes through a `CHANGELOG.md` entry. Retired files are retained, not deleted.
