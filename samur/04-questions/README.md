# Unresolved Questions

Open questions with stakes. Each question constrains future work until resolved.

## Entry format

```
# Q-<NNN> <Question>
Status: OPEN
Date: YYYY-MM-DD
Related: [canon / hypothesis / research IDs]
Why it matters: what this constrains.
Current best guesses: [H-IDs]
```

## Closure

- **Promote:** the answer becomes CANON (or HYPOTHESIS); the question is closed with a pointer.
- **Close as answered-negatively** (e.g., "why did X not spread?"): the answer is retained as a record of **historical negative space** — this is the Phase 5 negative-space log. Never deleted.
- **Close as out-of-scope** with a one-line reason.

All closures are logged in `CHANGELOG.md`.
