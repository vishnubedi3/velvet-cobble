# ESCALATION.md

When the guard cannot safely determine the answer. Documented and testable. Hosts must not invent a sixth decision.

| Situation | Action |
|---|---|
| Consistent with `main` and current Arena direction (or none relevant) | **Proceed** (`PASS`) |
| Safe vs `main`; ignores/diverges from strong or provisional Arena; or uses working material labeled | **Proceed with warning** (`PASS_WITH_WARNINGS`) |
| Uninspected Arena; unresolved overlap; competing Arena directions; insufficient story-time | **Request clarification** (`REQUIRES_CLARIFICATION`) |
| Violates established `main` canon; charter forbids the kind; draft cited as canon; output contaminates; continuity break; generator redefines constraints | **Block** (`BLOCK`) |
| User explicitly wants the incompatible established outcome | **Request explicit canon change** (`CANON_CHANGE_REQUIRED`) |
| Host cannot read refs or required sources | **Human / host error** — no canon decision |

Human review is required for:

- `CANON_CHANGE_REQUIRED`
- high-impact admission onto `main`
- mystery-resolution attempts
- any host error (missing branches)

Human review is **not** required for ordinary PASS / PASS_WITH_WARNINGS / BLOCK. Those are the guard doing its job.

Uncertainty is not a PASS. Uncertainty is not a BLOCK unless a blocking class already fired.
